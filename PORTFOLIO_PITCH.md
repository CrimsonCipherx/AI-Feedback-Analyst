# Portfolio pitch

## One-line description
AI-powered customer feedback analytics app that converts unstructured retail feedback into actionable business insights.

## Interview story
I spent years working directly with retail customers, so I understood the operational problem before I wrote the software. I built this application to classify customer feedback, identify root causes, recommend actions, and give managers a dashboard they can use to spot recurring issues quickly.
